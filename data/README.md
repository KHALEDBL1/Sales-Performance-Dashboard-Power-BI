# Dataset Guide

The `data` folder contains the CSV files used by the Power BI report.

| File | Purpose | Key fields |
|---|---|---|
| `AdventureWorks_Customers.csv` | Customer attributes | CustomerKey, demographics, education, occupation |
| `AdventureWorks_Products.csv` | Product master and pricing | ProductKey, ProductName, ProductCost, ProductPrice |
| `AdventureWorks_Product_Categories.csv` | Product category lookup | ProductCategoryKey, CategoryName |
| `AdventureWorks_Product_Subcategories.csv` | Product subcategory lookup | ProductSubcategoryKey, SubcategoryName, ProductCategoryKey |
| `AdventureWorks_Returns.csv` | Product return transactions | ReturnDate, ProductKey, ReturnQuantity |
| `AdventureWorks_Sales_2015.csv` | 2015 sales transactions | OrderDate, OrderNumber, ProductKey, CustomerKey, OrderQuantity |
| `AdventureWorks_Sales_2016.csv` | 2016 sales transactions | OrderDate, OrderNumber, ProductKey, CustomerKey, OrderQuantity |
| `AdventureWorks_Sales_2017.csv` | 2017 sales transactions | OrderDate, OrderNumber, ProductKey, CustomerKey, OrderQuantity |

AdventureWorks is a Microsoft sample database used for education and demonstrations. See the attribution links in the main README.
